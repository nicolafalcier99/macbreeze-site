• The menu bar readout has a Compact setting: the same readings in smaller type, for a menu bar that is already full. MacBreeze's own icon can be hidden too, leaving just the numbers.
  • Right-click the menu bar icon for quick actions: Blast, Open Dashboard, Quit.
  • Clicking the menu bar icon no longer flashes a dark box behind it.
  • MacBreeze can leave the Dock while its window is closed, so it lives in the menu bar alone. Turn it off in Preferences if you want the Dock icon and app menu always there.
  • Blast no longer makes the fan mode picker jump to Auto. Your setting stays on screen and comes back when Blast ends.
  • Each fan's real speed now stays visible while an app automation is running.
  • Descriptions under settings no longer run underneath the switch they describe.
  • In your licence's device list, "This Mac" and the Mac that manages the licence are now marked in colour.
