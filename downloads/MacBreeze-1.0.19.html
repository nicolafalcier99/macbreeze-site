⚠️ Important: update as soon as possible

  • Please install this update now. It fixes problems with the fan helper and with Blast that can leave fan control not working. Earlier versions can be asked to update to this one as a required install.

New

  • If the fan helper is left behind by an update, MacBreeze now replaces it automatically when restarting it is not enough.
  • Settings → Fan Control always has Reinstall Fan Helper, even when nothing is wrong.
  • Blast works while a safety trip holds the fans. Before, pressing Blast did nothing until the trip ended.

Fixed

  • Install and Relaunch now quits MacBreeze and installs the update.
